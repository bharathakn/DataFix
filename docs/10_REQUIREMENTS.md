# 10 · Requirements: APIs, Data and Software

Status as of Phase 0 (2026-11-19).

## 1. External APIs

| API | Needed for | Cost / key | Status |
|---|---|---|---|
| **Google Gemini API** | Explanations, chatbot, root-cause narrative, plain-English rules | Free tier; key from Google AI Studio (aistudio.google.com → Get API key) | **Needed from you** → put in `.env` as `GEMINI_API_KEY` |
| India Post PIN API (`api.postalpincode.in`) | PIN → post offices/district/state lookups for PINs not in the bundled reference | Free, no key | Working, results cached in `data/reference/raw/api_cache.json` |
| data.gov.in Open Data | Full All-India Pincode Directory (≈165k post offices) for offline PIN validation | Free; CSV download may need a free login | **Optional, recommended** (see §2) |

No other APIs are needed. The app runs fully without Gemini (offline templates).

## 2. Datasets

| Dataset | Purpose | Status |
|---|---|---|
| Demo customers + orders (`data/demo/`) | Demo, tests, benchmark ground truth | ✅ Generated by `scripts/make_demo_data.py` (seed 42) |
| PIN reference (`data/reference/pincodes.csv`) | PIN validation, PIN ↔ address repair | ✅ Seed version: 67 PINs / 365 offices (12 demo cities + every real PIN one digit from `40001`) |
| Full India Post directory | PIN validation on **any** uploaded file (a judge's own data) without hitting the API per PIN | ⏳ Optional: download "All India Pincode Directory" CSV from data.gov.in, drop it into `data/reference/raw/`, run `python3 scripts/build_pin_reference.py` |
